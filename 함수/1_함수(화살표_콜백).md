# 🚀 자바스크립트 함수 정복: 콜백 함수와 화살표 함수

자바스크립트를 배우다 보면 가장 먼저 마주치는 큰 산이 바로 **'콜백 함수(Callback Function)'**와 **'화살표 함수(Arrow Function)'**입니다. 이름만 들으면 아주 복잡해 보이지만, 실생활에 빗대어 보면 정말 간단한 개념이랍니다! 

---

## 1. 콜백 함수 (Callback Function): "다 되면 알려줘!"

**콜백 함수**는 다른 함수에게 "나중에 너 할 일 다 끝나면 이것 좀 실행해 줘"라고 **전달해 주는 함수**를 말합니다.

### ☕ 실생활 비유: 카페의 진동벨
우리가 카페에서 커피를 주문할 때를 생각해 볼까요?
1. 카운터에서 커피를 주문합니다.
2. 점원이 **진동벨**을 줍니다.
3. 우리는 자리에 앉아 내 할 일을 합니다.
4. 커피가 완성되면 진동벨이 울리고(Call), 우리는 커피를 가지러 갑니다(Back).

여기서 **'진동벨'**이 바로 콜백 함수입니다! 자바스크립트는 성격이 아주 급해서 한 가지 일이 끝날 때까지 가만히 기다리지 않고 다음 코드를 읽어버립니다. 그래서 "이 작업 끝나면 이 진동벨(콜백 함수)을 울려!"라고 예약해 두는 방식을 아주 많이 사용합니다.

---

## 2. 화살표 함수 (Arrow Function): "짧고 굵게 말할게"

**화살표 함수**는 기존의 함수 작성 방식을 **더 짧고 간결하게** 줄여 쓰는 최신 문법입니다. `=>` 모양이 화살표를 닮았다고 해서 붙여진 이름입니다.

### 📱 실생활 비유: 편지와 카카오톡
* **기존 함수 (일반 함수):** 격식을 갖춰 쓰는 '종이 편지' 같습니다. "안녕하십니까. 저는 함수라고 합니다..." 처럼 써야 할 기본 양식(`function` 키워드 등)이 깁니다.
* **화살표 함수:** 친구에게 보내는 '카카오톡 메시지' 같습니다. 불필요한 인사말은 쏙 빼고 핵심만 `=>` 기호를 사용해 짧고 명확하게 전달합니다. 

콜백 함수를 사용할 때 코드가 너무 길어지는 것을 막기 위해, 이 화살표 함수를 세트로 아주 많이 사용한답니다!

## 3. 🚨 초보자가 가장 흔히 하는 실수 (트러블슈팅 가이드)

이 두 가지 개념을 처음 배울 때 90% 이상의 입문자가 겪는 실수입니다. 꼭 기억해 두세요!

### ❌ 실수 1: 콜백 함수를 전달할 때 괄호 `()`를 붙이는 실수
진동벨(콜백 함수)은 "커피가 완성되면" 울려야 합니다. 
그런데 함수 이름 뒤에 괄호 `()`를 붙이면, 전달하자마자 그 자리에서 바로 실행되어 버립니다!
* `setTimeout(진동벨(), 1000);` (❌ 에러! 진동벨을 받자마자 바로 울려버림)
* `setTimeout(진동벨, 1000);` (⭕ 정답! 괄호를 빼야 나중에 울리도록 잘 전달됨)

### ❌ 실수 2: 화살표 함수에서 중괄호 `{}`와 `return`의 관계
화살표 함수는 코드가 한 줄일 때 중괄호 `{}`를 생략하면 결과값을 자동으로 반환(return)해 줍니다. 하지만 중괄호를 썼다면 반드시 `return`을 직접 적어주어야 합니다.
* `const add = (a, b) => a + b;` (⭕ 정답! 자동으로 a+b를 돌려줌)
* `const add = (a, b) => { a + b };` (❌ 에러! 중괄호를 썼는데 return이 없어서 아무것도 안 돌려줌)
* `const add = (a, b) => { return a + b };` (⭕ 정답!)
